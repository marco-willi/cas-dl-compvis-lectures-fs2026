The Classification Task

Image Classification

Figure 1: Assign an image to one of \(K\) predefined categories.

The task that sparked the deep learning revolution (Krizhevsky et al. (2012)).

Variants

  • Multi-class: exactly one of \(K > 2\) classes (species ID)
  • Binary: \(K = 2\) (animal present vs. empty)
  • Multi-label: multiple labels from one shared set (deer + bird)
  • Multi-task: multiple separate label sets (species, behavior, time-of-day)

Multi-label vs. Multi-task

Property Multi-label Multi-task
Label sets One shared set Multiple separate sets
Example deer ✓, bird ✓, fox ✗ species: deer / behavior: grazing / time: day
Output head One head, sigmoid per class One head per task
Loss BCE per class Sum of per-task losses

Modelling Classification

Parametric Approach

A model with parameters \(\theta\) outputs a score \(\hat{y}^{(i)}\):

\[ \hat{y}^{(i)} = f(\theta, \mathbf{x}^{(i)}) \]

\(\theta\) — all learnable parameters (conv filters, FC weights, biases, …).

Softmax Classifier

Interpret outputs as class probabilities:

\[ P(Y = k \mid X = \mathbf{x}^{(i)}) = \sigma(\mathbf{z})_k = \frac{e^{z_k}}{\sum_{j=1}^K e^{z_j}} \]

  • \(\mathbf{z}\) — logits (unbounded, real-valued)
  • \(\sigma(\mathbf{z})\) — valid probability distribution (sums to 1, all in \([0, 1]\))

Logits → Probabilities

Logits can be any real number — softmax always produces a valid distribution.

Cross-Entropy: The Idea

A good model assigns high probability to the correct class.

  • True class “deer”, \(P(\text{deer}) = 0.95\) → small loss
  • True class “deer”, \(P(\text{deer}) = 0.02\) → very large loss (confidently wrong)

Cross-Entropy Formula

For one sample with one-hot label \(\mathbf{y}\) and prediction \(\hat{\mathbf{y}}\):

\[ CE = -\sum_{j=1}^K y_j \log \hat{y}_j \]

Since \(\mathbf{y}\) is one-hot (only true class \(c\) has \(y_c = 1\)):

\[ CE = -\log \hat{y}_c \]

Just the negative log-probability of the correct class.

Cross-Entropy: Full Dataset

\[ L(\mathbf{X}, \mathbf{y}, \theta) = -\frac{1}{N} \sum_{i=1}^N \sum_{j=1}^K y_j^{(i)} \log \hat{y}_j^{(i)} \]

Equivalent to maximum likelihood under the categorical model.

True vs. Predicted

Asymmetric Penalty

  • Confident & correct (\(\hat{y}_c \to 1\)) → loss \(\to 0\)
  • Uncertain (\(\hat{y}_c = 0.5\)) → loss \(\approx 0.69\)
  • Confident & wrong (\(\hat{y}_c \to 0\)) → loss \(\to \infty\)

Drives models to be both accurate and well-calibrated.

Quiz: Which Loss is Higher?

A model predicts:

  • \(P(\text{deer}) = 0.4\) for an image that is a deer
  • \(P(\text{deer}) = 0.6\) for an image that is a fox

Which prediction gives the higher cross-entropy?

The first. \(-\log(0.4) \approx 0.92\) — low probability assigned to the true class.

For the second image, the true class is fox — only \(P(\text{fox})\) matters, not \(P(\text{deer})\).

Maximum Likelihood Connection

Likelihood of the dataset: \[ P(\mathbf{y} \mid \theta, \mathbf{X}) = \prod_{i=1}^N \prod_{j=1}^K P(Y = j \mid X = \mathbf{x}^{(i)})^{y_j^{(i)}} \]

Take \(-\log\) → minimize → identical to cross-entropy.

Minimizing CE = maximizing likelihood.

Architecture Overview

The CNN Pipeline

A CNN backbone extracts hierarchical features.

A classification head (e.g. an FC layer) maps features → \(K\) logits.

Softmax + cross-entropy turn logits into a learnable classifier.

Architecture Progression

  • AlexNet (2012) — 8 layers, GPU-trained, won ImageNet
  • VGG (2014) — 16–19 layers, all \(3 \times 3\) kernels
  • ResNet (2015) — 50–152+ layers via residual connections
  • ConvNeXt (2022) — modernized CNN, competitive with Vision Transformers

Not overfitting — an optimization problem.

Residual Connections

Source: Johnson (2019)

\[ \mathbf{x}_{l+1} = \mathbf{x}_l + F(\mathbf{x}_l) \]

Learn the change, not the full transformation.

If a layer has nothing to add: \(F(\mathbf{x}_l) \approx 0\) → identity.

Why Residuals Work

Source: Li et al. (2018)

Skip connections smooth the loss surface → optimization works.

ConvNeXt (2022)

Liu et al. (2022)

  • Larger kernels
  • Different activations
  • LayerNorm instead of BatchNorm
  • Depthwise separable convolutions

Which Architecture?

Don’t be a hero.

Use proven, off-the-shelf architectures:

  • ResNet-50 / ResNet-101 — reliable baseline (slightly dated)
  • EfficientNet — when size or speed matters
  • ConvNeXt — SOTA CNN, competitive with ViTs

Choose based on accuracy, FLOPs, memory, available data.

Summary

Key Takeaways

  • Classification has variants — multi-class, binary, multi-label, multi-task
  • Softmax turns logits into a valid probability distribution
  • Cross-entropy = \(-\log \hat{y}_c\) — punishes confident wrong predictions hard
  • Architecture trend: AlexNet → VGG → ResNet → ConvNeXt
  • Residual connections smooth the loss landscape, enable depth
  • Don’t be a hero — start with a proven backbone
