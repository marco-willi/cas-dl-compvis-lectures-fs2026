Modelling Classification

From Image to Logits

A classifier maps an input image to one score per class:

\[ \mathbf{z} = f_\theta(\mathbf{x}) \]

  • \(\mathbf{x}\): input image tensor
  • \(f_\theta\): neural network with learnable parameters
  • \(\mathbf{z} \in \mathbb{R}^K\): logits, one score for each class

Logits are not probabilities, they can be negative, positive, small, or large.

Softmax Classifier

A classifier outputs one logit per class:

\[ \mathbf{z} = f_\theta(\mathbf{x}), \qquad \mathbf{z} \in \mathbb{R}^K \]

Softmax converts logits into class probabilities:

\[ P(Y = k \mid X = \mathbf{x}^{(i)}) = \sigma(\mathbf{z})_k = \frac{e^{z_k}}{\sum_{j=1}^K e^{z_j}} \]

  • \(\mathbf{z}\) logits: unbounded class scores
  • \(\sigma(\mathbf{z})\) probabilities: positive and sum to 1
  • Larger logits receive larger probabilities

Logits → Probabilities

Logits can be any real number — softmax always produces a valid probability distribution.

Cross-Entropy: The Idea

A good classifier assigns high probability to the correct class.

For an image whose true class is deer:

  • \(P(\text{deer}) = 0.95\) → small loss
  • \(P(\text{deer}) = 0.40\) → moderate loss
  • \(P(\text{deer}) = 0.02\) → very large loss

Cross-entropy only cares about the probability assigned to the true class.

Cross-Entropy Formula

For one sample with one-hot label \(\mathbf{y}\) and predicted probabilities \(\hat{\mathbf{y}}\):

\[ CE(\mathbf{y}, \hat{\mathbf{y}}) = -\sum_{j=1}^K y_j \log \hat{y}_j \]

Because \(\mathbf{y}\) is one-hot, only the true class \(c\) contributes:

\[ CE = -\log \hat{y}_c \]

So training minimizes the negative log-probability of the correct class.

Quiz: Which Loss is Higher?

A model predicts:

  • \(P(\text{deer}) = 0.4\) for an image that is a deer
  • \(P(\text{deer}) = 0.6\) for an image that is a fox

Which prediction gives the higher cross-entropy?

The first prediction.

For the deer image:

\[ CE = -\log(0.4) \approx 0.92 \]

For the fox image, \(P(\text{deer})\) is irrelevant. Cross-entropy depends only on the probability assigned to the true class, here \(P(\text{fox})\).

The Classification Pipeline

A classification model usually has two parts:

  • Backbone: extracts visual features from the image
  • Classification head: maps features to \(K\) logits

Conceptually:

\[ \text{image} \rightarrow \text{features} \rightarrow \text{logits} \rightarrow \text{probabilities} \]

Training uses logits + labels to compute cross-entropy loss.

Architecture Progression

  • AlexNet (2012): 8 layers, made deep CNNs dominant on ImageNet
  • VGG (2014): 16–19 layers, simple repeated \(3 \times 3\) convolution blocks
  • ResNet (2015): 50–152+ layers, residual connections enabled much deeper networks
  • ConvNeXt (2022): modernized CNN design, competitive with Vision Transformers

The common pattern: better feature extractors → better classification backbones.

Which Architecture?

Don’t be a hero.

Start with a proven pretrained backbone:

  • ResNet-50 / ResNet-101: reliable baseline
  • EfficientNet: good when size or speed matters
  • ConvNeXt: strong modern CNN backbone
  • Vision Transformer / Swin / DINO-style features: strong when data and compute allow

Choose based on accuracy, speed, memory, available data, and deployment constraints.

Summary

Key Takeaways

  • Image classification maps an image to class logits.
  • Softmax converts logits into class probabilities.
  • Cross-entropy penalizes low probability assigned to the true class.
  • Most classifiers use a backbone plus a small classification head.
  • Architecture evolution: AlexNet → VGG → ResNet → ConvNeXt / ViT.
  • Start with a proven pretrained backbone; only customize when needed.
