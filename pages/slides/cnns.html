Why CNNs Work for Images

Image Properties

Image Source

  • High-dimensional — \(224 \times 224 \times 3 = 150{,}528\) values
  • Locality — nearby pixels are correlated
  • Stability under transformations — translations, color, rotations
  • Hierarchical structure — pixels → edges → textures → objects

How are Nearby Pixels Related?

  • Object coherence — pixels in an object share color/texture
  • Smooth transitions — gradual, not random
  • Texture patterns — repeating local statistics
  • Edges/boundaries — span multiple neighbors

Patterns at Different Locations

If an MLP learns “cat in the center”, what about “cat in the corner”?

  • Parameter explosion — separate weights per position
  • Data hungry — must see the pattern at every location
  • Poor generalization — fails on unseen positions

MLP Demo — try drawing a digit at different positions.

MLPs on Images — Three Limitations

  • High-dimensional — size scales with input
  • No locality — ignores spatial structure
  • No translation stability — must learn position-specific patterns

Invariance and Equivariance

Invariant — output unchanged by transformation: \[f(g(\mathbf{x})) = f(\mathbf{x})\] “I don’t care about the transformation.”

Equivariant — output transforms with input: \[f(g(\mathbf{x})) = g(f(\mathbf{x}))\] “I transform my output the same way.”

Invariance — Classification

Equivariance — Detection

Task → Required Property

Task Property Why
Classification Translation invariance A cat is a cat anywhere
Detection Translation equivariance Box moves with the object
Segmentation Translation equivariance Pixel labels shift with input

The CNN Idea

  1. Local connectivity — neuron sees a small spatial region
  2. Parameter sharing — same filter at every position
  3. Translation equivariance — input shifts → output shifts

These encode our prior knowledge about images.

Local Connectivity

Source: Johnson (2019)

Result: fewer parameters, preserved structure, position-agnostic detectors.

Inductive Bias

  • MLPs — minimal bias, very general, data-hungry
  • CNNs — assume locality + translation equivariance
  • Transformers — assume long-range dependencies
  • GNNs — assume graph structure

Choosing an architecture = choosing which assumptions to bake in.

The Convolution Operation

\[ S(i, j) = (K * I)(i, j) = \sum_m \sum_n I(i + m, j + n)\, K(m, n) \]

  • \(I\) — input
  • \(K\) — kernel (smaller than \(I\))
  • \(i, j\) — spatial position in the output

Filter vs. Kernel

  • Kernel — 2-D (\(H \times W\))
  • Filter — 3-D (\(C \times H \times W\)); a stack of \(C\) kernels

Dilation

Why Dilation?

  • Larger receptive field without more layers
  • Same parameter count
  • Multi-scale features with varying dilation rates

Used in DeepLab (segmentation), WaveNet (audio), Dilated ResNets.

3×3 with dilation 2 → receptive field of 5×5, only 9 params (vs. 25).

Output Size Formula

\[ o = \left\lfloor \frac{i + 2p - d \cdot (k-1) - 1}{s} + 1 \right\rfloor \]

  • \(i\) — input side length
  • \(k\) — kernel size
  • \(p\) — padding (per side)
  • \(s\) — stride
  • \(d\) — dilation

Quiz: Output Shape

\(i = 32, \; k = 3, \; p = 1, \; s = 2, \; d = 1\). Find \(o\).

\[o = \left\lfloor \frac{32 + 2 - 1 \cdot 2 - 1}{2} + 1 \right\rfloor = \left\lfloor \frac{31}{2} + 1 \right\rfloor = 16\]

Intuition: stride 2 ≈ halves the spatial dim; padding preserves a bit.

Parameter Count

\[ \text{Weights} = k \times k \times C_\text{in} \times C_\text{out} \]

\[ \text{Total} = k \times k \times C_\text{in} \times C_\text{out} + C_\text{out} \] (plus one bias per output channel)

Quiz: Parameter Counting

Layer: \(C_\text{in} = 3, \; C_\text{out} = 64, \; k = 5\), with bias.

  • Weights: \(5 \times 5 \times 3 \times 64 = 4{,}800\)
  • Biases: \(64\)
  • Total: \(4{,}864\)

A fully connected alternative (\(32 \times 32 \times 3 \to 64\)): \[ 196{,}608 \quad \text{parameters} \;\; (\text{40× more!}) \]

Receptive Field Formula

\[ r_0 = \sum_{l=1}^L \left( (k_l - 1) \prod_{i=1}^{l-1} s_i \right) + 1 \]

Stacking small kernels grows the field efficiently.

Quiz: Receptive Field

  • Layer 1: kernel=3, stride=1
  • Layer 2: kernel=3, stride=2
  • Layer 3: kernel=5, stride=1

\(r_0 = (3-1)\cdot 1 + (3-1)\cdot 1 + (5-1)\cdot(1 \cdot 2) + 1\)

\(r_0 = 2 + 2 + 8 + 1 = \mathbf{13}\) → 13 × 13 receptive field.

Summary

Key Takeaways

  • MLPs flatten images → lose structure, explode in size
  • CNNs encode locality + parameter sharing + translation equivariance as inductive biases
  • Conv hyperparameters: kernel, stride, padding, dilation — control receptive field & output size
  • Stacked convs grow receptive fields and learn hierarchical features
  • Pooling, 1×1 conv, global avg pool — workhorse layers around convolutions
