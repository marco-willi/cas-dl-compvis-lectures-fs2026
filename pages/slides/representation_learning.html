Motivation

The Semantic Gap

Source

A human can describe this image in a sentence — pixels alone are a poor representation of what it depicts.

Natural Language as Compression

“A photograph of an elephant facing the camera, large tusks and ears, standing in a flat savannah, bright daylight, cloudy sky.”

Far fewer bits than the raw RGB image — yet preserves what matters.

Information Content

  • Raw image: \(640 \times 360 \times 3 \times 8 = 5{,}529{,}600\) bits
  • Description: ~\(170 \times 8 = 1{,}360\) bits
  • Compression: ~4000×

This is the spirit of representation learning — compact embeddings that retain task-relevant information.

The Vastness of Image Space

Figure 2: Possible images: \(255^{256 \times 256 \times 3}\) — astronomical. Natural images occupy a tiny manifold.

A good embedding finds coordinates within the natural-image manifold.

What Is a Representation?

Definition

\[ \mathbf{z} = f(\mathbf{x}) \in \mathbb{R}^d \]

  • \(f\) — encoder
  • \(\mathbf{z}\) — representation / embedding
  • Goal: distances \(\|\mathbf{z}_i - \mathbf{z}_j\|_2\) reflect semantic similarity

  • Same class, different lighting → moderate distance (illumination invariance)
  • Different classes → far apart (inter-class)
  • Animals vs. cars → very far (domain shift)

Data Space → Representation Space

Figure 5: The encoder \(f\) maps \(\mathbf{x}_i\) to \(\mathbf{z}_i\). Semantic relationships emerge as distances and clusters.

Invariance vs. Selectivity

Invariance: \[\|f(\mathbf{x}) - f(g(\mathbf{x}))\|_2 < \epsilon\] for nuisance \(g\) (lighting, flips, crops).

Selectivity: \[\|f(\mathbf{x}_i) - f(\mathbf{x}_j)\|_2 > \delta\] for semantically distinct \(\mathbf{x}_i, \mathbf{x}_j\).

“Nuisance” Is Task-Dependent

  • Product retrieval — color is discriminative; color-invariant ≠ helpful
  • Medical imaging — orientation is meaningful; rotation-invariant can destroy info
  • Size estimation — scale matters; scale-invariant kills the signal

Match invariances to your task. Discard only true nuisances.

Representation vs. Classification

Classification: predict a fixed label.

Representation learning: build a reusable embedding that transfers across many tasks — without retraining the encoder.

Learning Paradigms

Three Paradigms, Same Architecture

  • Supervised — labels (ResNet/ViT on ImageNet)
  • Weakly supervised — image–text pairs (CLIP)
  • Self-supervised — no labels (MAE, SimCLR, DINO)

CLIP — Zero-Shot Classification

At inference, text prompts become classifiers:

“a photo of a {dog, cat, beach, …}” → text embeddings → pick the closest to the image embedding.

No labeled images needed for the target task.

CLIP Loss (optional)

Symmetric InfoNCE over image–text pairs:

\[ \mathcal{L}_{i \to t} = -\frac{1}{N}\sum_i \log \frac{\exp(s_{ii})}{\sum_j \exp(s_{ij})} \]

\(s_{ij} = \alpha \, \tilde{\mathbf{v}}_i^\top \tilde{\mathbf{t}}_j\) — cosine similarity scaled by learned temperature \(\alpha\).

\[\mathcal{L}_{\text{CLIP}} = \tfrac{1}{2}(\mathcal{L}_{i \to t} + \mathcal{L}_{t \to i})\]

Self-Supervised Learning

No human labels. Training signal comes from the data itself.

  • Reconstruct masked patches (MAE)
  • Match augmented views (SimCLR)
  • Match teacher’s distribution (DINO)

Masked Autoencoding (MAE)

Figure 8: Mask ~75% of patches → encoder sees only visible patches → decoder reconstructs the rest.

Post-training, discard the decoder and use the encoder for downstream tasks.

MAE Loss (optional)

\[ \mathcal{L}_{\text{MAE}} = \frac{1}{|\mathcal{M}|} \sum_{p \in \mathcal{M}} \|\hat{X}_p - \tilde{X}_p\|_2^2 \]

Only the masked patches contribute. Targets are normalized pixels.

High mask ratio + asymmetric encoder/decoder → efficient pretraining, strong transfer.

Contrastive Learning — SimCLR

InfoNCE Loss (optional)

\[ \mathcal{L}_{\text{InfoNCE}} = -\log \frac{\exp(\text{sim}(z_i, z_i^+)/\tau)}{\exp(\text{sim}(z_i, z_i^+)/\tau) + \sum_j \exp(\text{sim}(z_i, z_j^-)/\tau)} \]

  • \(z_i^+\) — augmented view of same image
  • \(z_j^-\) — other images in the batch
  • Needs large batches (256–4096) for enough negatives

Self-Distillation — DINO

Figure 10: Student matches the teacher’s output distribution. Teacher = EMA of student weights.

No explicit negatives. Smaller batches work.

DINO Series

  • DINO (Caron et al. (2021))
  • DINOv2 (Oquab et al. (2024))
  • DINOv3 (Siméoni et al. (2025))

Bonus: produces strong global ([CLS]) and local (patch) features.

DINOv3 Composite Loss (optional)

Figure 11: Global DINO · Local iBOT · KoLeo uniformity · Gram anchoring.

DINOv3 Components (optional)

\[ \mathcal{L} = \mathcal{L}_{\text{DINO}} + \lambda_{\text{iBOT}}\, \mathcal{L}_{\text{iBOT}} + \lambda_{\text{KoLeo}}\, \mathcal{L}_{\text{KoLeo}} + \lambda_{\text{Gram}}\, \mathcal{L}_{\text{Gram}} \]

  • DINO — student matches teacher distribution (global crops)
  • iBOT — masked patch prediction
  • KoLeo — push [CLS] embeddings apart (uniformity)
  • Gram — patch similarity consistency (refinement)

Global vs. Local Representations

Global

A single embedding per image — [CLS] token or global average pooling.

Captures image-level semantics. Use for:

  • Image classification
  • Image retrieval
  • Zero-shot recognition (CLIP)

Local

Spatially-resolved patch tokens. Each token describes a region.

Preserves position. Use for:

  • Semantic segmentation
  • Object detection
  • Dense prediction (depth, pose)

Quiz: Web-Shop Product Retrieval

Find shoes that look similar to the one a customer is viewing.

Global or local embedding?

Global — the query is image-level (“looks like this shoe overall”).

A single [CLS] token enables fast approximate nearest-neighbor search over millions of items.

For defect detection on the product surface → local patch tokens.

Which Representation Wins?

  1. DINOv2/v3 — default for vision-centric tasks
  2. CLIP — when zero-shot or text alignment is critical
  3. Supervised CNN — when compute is limited and broad categories suffice
  4. Pixel space — never (only exact-duplicate detection)

Warning: Task-Relevant Invariance

  • Color-invariant for flower classification → red vs. yellow tulips collapse
  • Rotation-invariant for medical imaging → orientation matters
  • Scale-invariant for size estimation → kills the signal

Preserve information — let the downstream model decide what to ignore.

Adapting Pretrained Models

Adaptation Hierarchy

  1. k-NN — no training, instant quality check
  2. Linear probe — frozen encoder, train a linear head
  3. LoRA / Adapters — parameter-efficient fine-tuning
  4. Partial fine-tune — unfreeze top layers
  5. Full fine-tune — last resort, large datasets

Choose by dataset size, domain similarity, compute budget.

Quiz

Q1: Why Pixel Similarity Fails

Why don’t raw-pixel distances capture semantic relationships?

Pixels measure low-level appearance (color, lighting, alignment) — not semantics.

Same elephant under different lighting → large pixel distance, despite identical semantics.

Good representations compress \(255^{H \times W \times C}\) → semantic coordinate system.

Q2: Invariance ↔︎ Selectivity Trade-off

Give an example where too much invariance hurts.

Flower classification with color-invariant features — red rose vs. yellow rose collapse to the same embedding.

Other examples:

  • Medical: rotation-invariance kills anatomical orientation
  • Size estimation: scale-invariance removes the signal
  • Materials: texture-invariance destroys wood vs. metal

Q3: DINO vs. SimCLR

What is the key advantage of self-distillation (DINO) over contrastive (SimCLR)?

No explicit negatives needed — works with smaller batches.

  • SimCLR — needs 256–4096 batches for enough negatives
  • DINO — student matches teacher (EMA), centering + sharpening yield emergent clustering

Bonus: DINO produces both global and local features.

Q4: Global vs. Local

When global, when local?

Global — image-level: classification, retrieval, zero-shot

Local — pixel/region-level: segmentation, detection, depth

Modern ViTs (DINOv2/v3) provide both — [CLS] for global, patch tokens for dense.

Summary

Key Takeaways

  • Representation = compact embedding \(\mathbf{z} = f(\mathbf{x})\) where distances reflect semantics
  • Invariance vs. selectivity — match to your task
  • Three paradigms: supervised · weakly supervised (CLIP) · self-supervised (MAE, SimCLR, DINO)
  • Global vs. local — image-level vs. region-level tasks
  • For vision-centric retrieval: DINOv2/v3 > CLIP > supervised > pixels
  • Adaptation: start simple (k-NN, linear probe) → fine-tune only when needed
